## About

I'm **agnogad**, a developer with a bias for shipping: I like problems I can solve with a single binary, a clean CLI, or a simple static site, and I'd rather write the tool I need than install a heavy framework to do it.

I write mostly in Rust and JavaScript/TypeScript, and I use AI tooling heavily in my workflow (Claude, OpenRouter) alongside the usual stack: Supabase, Cloudflare, Fly.io, Render, self-hosted servers on Contabo VPS, and uptime monitoring on UptimeRobot.

## Projects

**[agno](https://github.com/agnogad/agno)** — a fast, content-first static site generator written in Rust. Markdown and jinja-style templates go in, a static site comes out, all from a single 4.2 MB binary with no node and no bundler. It's MIT-licensed, in active development (v0.3.7), and its own documentation site ([agno-docs.pages.dev](https://agno-docs.pages.dev)) is built with agno itself. One of its commits ("feat: add search index and richer blog metadata") was selected for the [XERJ Corpus Hub](https://hub.xerj.org/contributors/agnogad), an open index of reference implementations that AI coding agents retrieve as worked examples — my code is used as a reference for agents solving the same problem.

**[pixiAnime](https://github.com/pixiAnime)** — an organization maintaining anime apps: **pixiDesktop** and **pixiAndroid**, with release and CI pipelines running on GitHub Actions.

**[kutuphanem](https://github.com/agnogad/kutuphanem)** — a Turkish book archive project (TypeScript).

**[Turkish-SkyStream](https://github.com/agnogad/Turkish-SkyStream)** — a Turkish-language extension repository for SkyStream (JavaScript).
