## 1. Ready-to-use bio

### Short bio
agnogad is a developer who builds fast open-source tools in Rust. His main project is agno, a static site generator that ships as a single binary.

### Longer bio
agnogad writes and maintains open-source developer tools. In October 2026 he released agno, a fast, content-first static site generator written in Rust. He started it because even Astro, which is supposed to be fast, felt slow for his own blog. agno is a single 4.2 MB binary with no Node.js and no bundler, and it has its own documentation site built with agno itself.

## 3. Featured project: agno

- What: a fast, content-first static site generator written in Rust, MIT license
- Install: `cargo install agno`
- One 4.2 MB binary, no Node.js, no bundler
- Templates use minijinja
- Latest version: v0.3.7 (October 26, 2026). It added a static Linux musl build with a pure-Rust syntax highlighter
- Speed (from the dev.to write-up, tested with up to 10,000 posts): cold builds 3.9-12.8x faster than Hugo and 16.7-185x faster than Astro. The README lists the methodology and caveats, so link to it when you quote these numbers
- The docs site is built with agno
- Why it exists: most frameworks felt slow to him, even Astro, so he wrote his own in Rust
- Recognition: a commit was selected for the XERJ Corpus Hub, an open reference library that AI coding agents search before writing code. Selected with the author's permission, under the repo's MIT license. The page showed 1 corpus, 6 files, 212 lines and 8 GitHub stars on the repo
- Write-up: "I built a static site generator in Rust because Astro felt slow" (dev.to, October 23, 2026): https://dev.to/agnogad/i-built-a-static-site-generator-in-rust-because-astro-felt-slow-3fbf
- jamstack.org PR #1153 (adds agno to the generators list) is still open, so do not claim agno is listed yet
