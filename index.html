I'm agnogad. I build software across Rust, the web, desktop and Android. I like problems I can solve with a single binary, a clean CLI, or a simple static site.

Most of my projects start with the same question: why is this heavier than the job? That's how agno began. But it's one thread. I also work on PixiAnime's desktop and Android clients, a web version of Kütüphanem, and Turkish-SkyStream. Different platforms, same instinct: keep the surface small and the behavior obvious.

I write about the process on dev.to, and post about Rust and the projects on X. Claude and OpenRouter are part of my daily workflow, next to Supabase, Cloudflare, Fly.io, Render and a Contabo VPS.

I'd rather write the tool I need than install a framework to do it.

agno

Static site generator v0.3.7 / MIT

The project that started with a complaint: Astro felt slow for my own blog. So I wrote a static site generator in Rust. Markdown and minijinja templates go in; plain files come out; one 4.2 MB binary, no Node, no bundler, no plugin runtime. The documentation site is built with agno itself.
